Agent Taxonomy

The cast of
characters.

🧠
Orchestrator
Director Agent

The conductor. Receives high-level goals, decomposes them into subtasks, delegates to specialist agents, and synthesizes the final result. Holds the global context and resolves conflicts.

Task Decomposition Planning CoT
🔍
Retrieval Agent
Memory & Context

Fetches relevant documents, embeddings, and live data from vector stores and APIs. Provides grounded context so other agents reason on facts, not hallucinations.

RAG Vector DB Embeddings
⚡
Executor Agent
Action & Tool Use

Bridges language and reality. Calls external APIs, runs code, writes to databases, and triggers automation workflows. The hands of the system.

Function Calling API Calls Code Exec
🛡
Critic Agent
Evaluation & Guardrails

Reviews outputs from other agents before they propagate. Checks for factual accuracy, safety violations, and quality thresholds. The system's immune response.

Self-Critique Safety QA
✍️
Content Agent
Generation Specialist

Specializes in producing structured outputs — articles, summaries, headlines, metadata. Fine-tuned prompts and format enforcement produce consistently high-quality content at scale.

Summarization Structured Output SEO
🔀
Router Agent
Classifier & Dispatcher

Classifies incoming tasks and routes them to the most capable specialist. Reduces latency and cost by avoiding unnecessary LLM calls and using the right model for each job.

Classification Model Routing Cost Opt.

How It Works

The ReAct loop.

Step 01
Perceive
The user submits a goal. The orchestrator parses intent, identifies ambiguities, and constructs an initial reasoning trace.
→
Step 02
Plan
Chain-of-thought reasoning breaks the goal into ordered subtasks. The router assigns each to the optimal specialist agent.
→
Step 03
Retrieve
The retrieval agent fetches grounding context from vector stores, live APIs, and memory banks. No hallucinations allowed.
→
Step 04
Act
Executor agents take actions in the real world — API calls, code execution, database writes, notifications fired.
→
Step 05
Evaluate
The critic agent audits results. If quality thresholds aren't met, the loop restarts with refined instructions. Otherwise, output is delivered.
→
