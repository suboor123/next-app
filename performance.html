Techniques

My Optimization Playbook

Every technique I reach for, categorised by the vital it primarily targets.

⚡

Code Splitting

LCPFCP

Route-based + dynamic imports. Ship only what the current page needs. Reduced initial bundle by 88% on ShopSphere.

🐤

Resource Hints

FCPLCP

preload, prefetch, preconnect, and Early Hints (103) to front-load critical resource discovery before HTML parsing completes.

🛈

Critical CSS Inline

FCP

Inline only above-fold CSS in <head>. Defer all other stylesheets with media trick. Eliminates render-blocking entirely.

🕓

Lazy Loading

LCP

loading="lazy" on off-screen images, IntersectionObserver for heavy components, dynamic imports for third-party scripts.

📦

Tree Shaking

FCPINP

ESM-only imports, sideEffect:false in package.json, custom Rollup/Vite configs to eliminate dead code paths.

🏠

ISR / Static Gen

LCPTTFB

Incremental Static Regeneration serves pre-built HTML from CDN edge. Sub-5ms TTFB globally, zero cold starts.

🧠

useTransition

INP

Mark expensive state updates as non-urgent. React keeps the UI responsive while preparing the next render in the background.

😉

Virtualisation

INPLCP

TanStack Virtual / react-window for lists of 1000+ items. Only DOM nodes in viewport are rendered — constant memory.

⛵

Server Components

LCPFCP

React Server Components and Suspense streaming. Data-fetching components run on server; HTML streams to client progressively.

📑

Memoisation

INP

React.memo, useMemo, useCallback placed surgically after profiling. Rule: never memoize without measuring — can hurt.

👔

CSS Containment

CLSINP

contain: layout style paint to isolate component reflows. content-visibility: auto to skip off-screen rendering entirely.

🎭

Long Task Yielding

INPTBT

Break tasks >50ms with scheduler.yield() / setTimeout chunks. Keeps main thread free for user input between chunks.

🖼️

AVIF / WebP Images

LCP

AVIF delivers 50% smaller files vs JPEG. Serve via <picture> with WebP fallback. Next/Image automates this pipeline.

🕪

Font Subsetting

FCPCLS

glyphhanger + Unicode-range to subset fonts to only used characters. 90KB IBM Plex → 8KB. font-display: optional kills FOUT.

💾

SVG Optimization

LCP

SVGO with custom plugin config: remove metadata, inline styles, inline fonts. Icon sprites instead of individual requests.

🔨

Bundle Analysis

FCPINP

@next/bundle-analyzer + source-map-explorer to find and eliminate duplicates, barrel file sins, and moment.js-scale bloat.

🌟

Compression

FCP

Brotli (level 11) for text assets, zopfli for PNG. Pre-compressed at build time — zero runtime CPU on CDN nodes.

📷

Responsive Images

LCPCLS

srcset + sizes attributes so mobile gets 320w images not desktop 1920w. Eliminates LCP bandwidth waste on phones.

🌐

HTTP/3 + QUIC

TTFBFCP

UDP-based QUIC eliminates head-of-line blocking. 0-RTT reconnects on mobile handoffs. 15–20% TTFB win over TLS/TCP.

🪟

Edge Caching

TTFBLCP

Cloudflare Cache Rules + Vercel Edge Network. stale-while-revalidate for dynamic content. Sub-5ms TTFB from 300+ PoPs.

🔌

Service Worker

LCPFCP

Workbox with network-first for API, stale-while-revalidate for assets. Instant repeat visits — content from cache before network.

🔄

API Response Caching

TTFB

Redis for per-user + shared caches, Upstash for serverless. Deduped in-flight requests with SWR/TanStack Query.

📈

RUM Monitoring

All

web-vitals.js + Sentry Performance + Vercel Speed Insights. Real users, real devices. Lab data is a lie — ship only when RUM confirms.

🔍

Lighthouse CI

All

Lighthouse CI on every PR, budget.json enforces score minimums. Any regression blocks merge. Performance debt never accumulates.
